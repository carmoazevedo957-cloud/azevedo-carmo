# Meus Jogos Educativos

Site em Flask para apresentar e baixar os jogos educativos em Python.

## Executar localmente

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Abra http://127.0.0.1:5000 no navegador.

Os jogos ficam em `jogos/` e podem ser baixados pela pagina inicial.
